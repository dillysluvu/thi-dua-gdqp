Hướng Dẫn Sử Dụng Nhanh
Áp dụng cho khóa hiện tại và các khóa tiếp theo.
  1. Chấm điểm: bấm Chấm Điểm trên thẻ trung đội, dùng các nút trừ nhanh hoặc nhập số. Nút Lưu & Sang Phòng Tiếp giúp chấm liên tục không cần đóng bảng.
  2. Tìm nhanh: gõ số trung đội (vd: 15), tên tòa (vd: C7), số phòng hoặc nội dung ghi chú.
  3. Dữ liệu tự lưu: mọi thay đổi được lưu vào trình duyệt trên thiết bị này, theo tên file HTML. Hãy xuất file .json định kỳ để sao lưu hoặc chuyển sang máy khác.
  4. Nhập Excel / Google Sheets: menu ⋮ → Nhập Excel / Google Sheets. Hỗ trợ file .xls, .xlsx, .csv, .tsv hoặc dán trực tiếp từ Excel/Sheets; có xem trước trước khi áp dụng.
  5. Khôi phục / chuyển máy: mở menu ⋮ → Nhập File Sao Lưu (.json). Dữ liệu cũ sẽ được thay thế sau khi xác nhận.
  6. In báo cáo: chọn ngày trên màn hình chính, sau đó menu ⋮ → In / Xuất PDF Báo Cáo. Trong hộp thoại in, chọn “Save as PDF” nếu cần gửi file.
Chuẩn bị cho khóa sau:
1. Xuất JSON khóa cũ 2. Cấu Hình Khóa Học 3. Đặt Lại Điểm 4. Cập nhật ngày 5. Chấm điểm
Lưu ý: xóa dữ liệu trình duyệt / dùng chế độ ẩn danh có thể làm mất dữ liệu đã lưu. File JSON là bản sao an toàn nhất.
