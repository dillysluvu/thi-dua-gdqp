Đồng Bộ Đám Mây
Tùy chọn kết nối Supabase để dùng dữ liệu trên nhiều thiết bị. Không bắt buộc để chấm điểm.
Cần chuẩn bị: một project Supabase, bảng course_sync và anon key. Dữ liệu vẫn được lưu cục bộ; đám mây chỉ là bản sao thêm.
SQL tạo bảng Supabase 
create table public.course_sync (
  id text primary key,
  course_id text not null,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.course_sync enable row level security;
create policy "course_sync_all" on public.course_sync
  for all using (true) with check (true);
Chỉ dùng anon key trong ứng dụng tĩnh. Với dữ liệu thật, nên giới hạn policy theo người dùng hoặc dùng backend trung gian.

Hướng Dẫn Sử Dụng Nhanh
Áp dụng cho khóa hiện tại và các khóa tiếp theo.
  1. Chấm điểm: bấm Chấm Điểm trên thẻ trung đội, dùng các nút trừ nhanh hoặc nhập số. Nút Lưu & Sang Phòng Tiếp giúp chấm liên tục không cần đóng bảng.
  2. Tìm nhanh: gõ số trung đội (vd: 15), tên tòa (vd: C7), số phòng hoặc nội dung ghi chú.
  3. Dữ liệu tự lưu: mọi thay đổi được lưu vào trình duyệt trên thiết bị này, theo từng khóa học. Hãy xuất file .json định kỳ để sao lưu hoặc chuyển sang máy khác.
  4. Nhập Excel / Google Sheets: menu ⋮ → Nhập Excel / Google Sheets. Hỗ trợ file .xls, .xlsx, .csv, .tsv hoặc dán trực tiếp từ Excel/Sheets; có xem trước trước khi áp dụng.
  5. Danh sách sinh viên & cán sự: menu ⋮ → Danh Sách Sinh Viên & Cán Sự. Có thể nhập Excel/CSV, thêm/sửa/xóa, lọc theo phòng/trung đội và gán chức vụ Tiểu đội trưởng, Trung đội trưởng, Phó đại đội trưởng. Bấm SV: n trên thẻ để mở đúng trung đội.
  6. Cộng tác nhóm: menu ⋮ → Cộng Tác Nhóm. Cần cấu hình Supabase trước. Nhiều người có thể cùng sửa; thay đổi được báo qua Realtime và vẫn tự đồng bộ mỗi 15 giây nếu Realtime không khả dụng.
  7. Khôi phục / chuyển máy: mở menu ⋮ → Nhập File Sao Lưu (.json). Dữ liệu cũ sẽ được thay thế sau khi xác nhận.
  8. In báo cáo: chọn ngày trên màn hình chính, sau đó menu ⋮ → In / Xuất PDF Báo Cáo. Trong hộp thoại in, chọn “Save as PDF” nếu cần gửi file.
Chuẩn bị cho khóa sau:
1. Xuất JSON khóa cũ 2. Cấu Hình Khóa Học 3. Đặt Lại Điểm 4. Cập nhật ngày 5. Chấm điểm
Lưu ý: xóa dữ liệu trình duyệt / dùng chế độ ẩn danh có thể làm mất dữ liệu đã lưu. File JSON là bản sao an toàn nhất.
